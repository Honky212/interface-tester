# 用例工程文件说明（给不写代码的同事）

> **这份文档给谁看**：不写代码的同事。看完你会知道——项目文件夹里那些文件分别是干嘛的、
> **哪些你该动、哪些千万别动**、以及遇到常见问题该怎么办。
>
> **你不需要会**：编程、命令行、Git。全文没有一行需要你敲的代码。
> 想看技术细节（每个文件的行为、报错含义），见技术版 [`使用说明-用例级.md`](使用说明-用例级.md)。

## 一、先用一句话理解这套东西

我们的接口自动化测试，所有内容都放在**一个文件夹**里（下面简称「用例工程」）。

这个文件夹里其实只有三类东西：

| 类别 | 谁产生的 | 你需要做什么 |
| --- | --- | --- |
| **测试用例** | 你 / 测试同学写的 | ✅ 平时主要改这个 |
| **几个「配置小文件」** | 一开始建好，之后很少动 | ⚠️ 知道它们是干嘛的；改之前先看一眼本文第五节 |
| **运行日志 / 报告** | 工具自动生成 | ❌ 不用管，看结果就行 |

打个比方：这个文件夹像**一间厨房**——
「用例」是你手上的菜谱；「配置小文件」是灶台、水龙头、调料架（装一次、长期用）；
「日志和报告」是每次做完菜留下的记录。

## 二、文件夹长什么样

下面每一行都有中文注释。**★ = 必须有**，**○ = 按需**。

```
我的接口测试/                 ← 整个项目就放在这个文件夹里
│
├── debugtalk.py           ★ 「门牌号」：告诉工具"这里是一个项目"。内容可以是空的
├── .env                   ○ 「环境小本子」：记接口地址、账号、密码
├── conftest.py            ○ 「开场与收场」：登录一次给大家用、跑完清理数据
│
├── 登录.yml                ★ 测试用例（你可以照格式加）
├── 下单.yml                ★ 测试用例
├── 公共_登录.yml            ○ 被别的用例重复使用的公共步骤
│
├── data/                  ○ 数据表格（Excel 另存的 CSV）
│   └── 账号.csv
├── schemas/               ○ "接口应该返回什么样"的规则文件
│   └── 登录.json
│
└── logs/                  （工具自动生成，别删别改）
```

> 你可能注意到后缀有 `.py` / `.yml` / `.csv` / `.json` / `.env`。
> **后缀只是「文件类型」的标记，不用背**——第三节会逐个告诉你每种是干嘛的。

## 三、每个文件是干什么的

### 3.1 `debugtalk.py` —— 项目的「门牌号」（★ 必须有）

- **它是干嘛的**：告诉工具「这个文件夹就是一个项目」。
- **为什么重要**：工具靠它找到「项目根目录」。它要是不在，工具会把「你当时所在的目录」
  当成项目根 → 于是**换个地方运行就报「找不到文件」**。这正是最常见的
  「我这跑不了、别人那能跑」。
- **内容**：可以**就是空的**（只留一行说明也行）。
- **你要不要动**：**不要删**。空着完全没问题。

### 3.2 `.env` —— 环境的「小本子」（○ 按需）

- **它是干嘛的**：把「这个环境的信息」集中记在一处——接口地址、账号、密码等。
- **好处**：换环境（测试 → 预发 → 生产）时**只改这一个文件**，用例一个字都不用动。
- **你要不要动**：✅ **可以改**，这是非技术同事最常改的文件之一。
- **两个注意点**：
  1. 里面有密码，**不能提交到代码仓库**（这点交给开发同事把关）；
  2. 文件名就叫 `.env`——最前面是一个英文句点，后面**没有任何后缀**。
     别改成 `.env.txt`，那样就不生效了。

### 3.3 `conftest.py` —— 开场与收场（○ 按需，通常由开发同事配）

- **它是干嘛的**：让整套测试有条理：
  - **开场**：例如**先登录一次**拿到「通行证」（token），后面所有用例共用，
    不必每条用例都登录；
  - **收场**：跑完把这次造出的测试数据清理掉，不给环境留垃圾；
  - **按条件跳过**：例如「生产环境不跑危险用例」。
- **你要不要动**：一般**不动**，需要时请开发同事配置。

### 3.4 用例文件（`.yml`）（★ 必须有）

- **它是干嘛的**：你平时写测试的地方——用接近表格的文本描述「调哪个接口、带什么参数、
  期望返回什么」。
- **你要不要动**：✅ **这就是你的主战场**。
- 写法和示例见 [`使用教程-项目级.md`](使用教程-项目级.md)。

### 3.5 `data/` 里的 CSV 表格（○ 按需）

- **它是干嘛的**：把「多组测试数据」放进表格，一条用例就能自动跑很多遍。
- **怎么维护**：**用 Excel 编辑**，保存时选「CSV UTF-8」。
- **你要不要动**：✅ 可以改。**第一行是列名，别动列名**。

### 3.6 `schemas/` 里的 `.json`（○ 按需）

- **它是干嘛的**：规定接口返回的**结构**——应该有哪些字段、什么类型、哪些是必填。
- **你要不要动**：⚠️ 一般由开发 / 测试同学维护（要按约定格式写）。

### 3.7 `logs/` 和每次生成的报告（❌ 不用管）

- 每次运行会**自动生成**，记录「发了什么请求、收到什么响应」。
- 报告是一个 HTML 文件，用**浏览器直接打开**就能看，不用装任何东西。
- 里面的密码、令牌会**自动打码**，不会明文显示。

## 四、你大概率会问的问题

| 问题 | 答案 |
| --- | --- |
| **换了服务器地址，改哪里？** | 改 `.env` 里的地址（前提是当初按 3.2 的约定把地址集中放在那里） |
| **为什么同一个用例，别人能跑、我报「找不到文件」？** | 多半是这两件事之一：① 项目里少了 `debugtalk.py`；② **运行时的「当前目录」不对**（工具是从当前目录开始找项目的）。在**项目文件夹**里执行就好 |
| **我能改 `.env` 里的密码吗？** | 能。但别提交到代码仓库，并且**同步通知用同一套用例的同事** |
| **密码会不会出现在报告里？** | 不会。请求与响应里的敏感信息（密码、令牌、Cookie）都会**自动打码**成 `******`；而被测接口本身收到的仍是真值 |
| **测试数据会不会把环境搞乱？** | 团队约定是「每次运行用唯一前缀造数据、跑完按前缀清理」（由 `conftest.py` 配合实现）。若发现没清干净，找开发同事看清理那一步 |
| **我能直接把需求写成用例吗？** | 能，照着现成用例改最快；写法见 [`使用教程-项目级.md`](使用教程-项目级.md) |
| **能在生产环境跑吗？** | 默认**不建议**。团队约定是「危险操作用例打标记，生产环境下自动跳过」——具体是否生效取决于项目的 `conftest.py`，跑生产前**务必先跟开发/测试负责人确认** |
| **每个项目都要建这一套吗？** | 是。每个「项目文件夹」各自有一份 `debugtalk.py`（以及按需的 `.env` / `conftest.py`），彼此互不干扰 |

## 五、「我该动哪个」速查

| 文件夹里的东西 | 你该怎么做 |
| --- | --- |
| 用例文件（`.yml`） | ✅ **放心改**——这是你的主战场 |
| `.env` | ✅ **可以改**（地址 / 账号）；改完别提交，并通知同事 |
| `data/` 里的 CSV 表格 | ✅ **可以改**（用 Excel，存成 CSV UTF-8，别动列名） |
| `schemas/` 里的 `.json` | ⚠️ 一般找开发 / 测试同学改 |
| `conftest.py` | ⚠️ 一般找开发同事改 |
| `debugtalk.py` | ❌ **别删**（里面是空的也没关系） |
| `logs/` 与报告文件 | ❌ 不用管，只看结果即可 |

## 六、小词典（看懂报告里的词）

| 词 | 大白话 |
| --- | --- |
| 用例 | 一条测试：调一个接口，检查结果对不对 |
| 接口 / API | 系统之间说话的方式——你给一个地址和参数，它回你数据 |
| 状态码 | 接口回的「结果编号」，`200` 通常表示成功 |
| PASSED / 通过 | 这条用例要检查的项目都对上了 |
| FAILED / 失败 | 有检查项没对上（可能真是缺陷，也可能期望值写旧了） |
| ERROR / 出错 | 用例本身没跑起来（例如地址写错、文件找不到） |
| token / 令牌 | 登录后拿到的「通行证」，后续请求带着它证明身份 |
| 环境（测试 / 预发 / 生产） | 同一套系统的不同「场地」，地址与账号都不一样 |
| 数据驱动 | 一条用例 + 一张表格 = 自动跑很多组数据 |
| 报告 | 一次运行的结果汇总，浏览器打开即可看 |
