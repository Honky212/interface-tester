# 旧系统用户信息接口（GBK 编码文档样本）

## GET /api/legacy/user/info

> **编码样本**：本文件刻意以 **GBK** 保存（老系统导出文档的常见形态）。
> 它的存在是为了让「文档编码探测」这条判据（§9.x P-6：`utf-8-sig → utf-8 → gbk → gb18030`）
> 有一个**端到端**样本——不是所有接口文档都是 UTF-8。

### 查询参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| uid | string | 是 | 用户编号 |

### 响应

```json
{"code": 0, "data": {"uid": "1001", "name": "张三", "dept": "研发部"}}
```

- `data.uid`：字符串
- `data.name`：字符串，**中文**（这正是 GBK 文档里的典型内容）
- `data.dept`：字符串

### 业务规则

- 用户不存在时返回 `code: 2001`，`message: 用户不存在`
