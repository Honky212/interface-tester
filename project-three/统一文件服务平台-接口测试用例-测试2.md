## 测试环境准备

### 前置条件
1. 获取测试环境的 `client_id` 和 `client_secret`
2. 准备测试用的应用ID（如 `/app1/`）
3. 准备测试文件（各种类型、大小的文件）

### 认证Token获取
```bash
# 获取Access Token
POST /oauth2/token
Content-Type: application/x-www-form-urlencoded

grant_type=client_credentials&client_id={your_client_id}&client_secret={your_client_secret}
```

## 一、认证模块测试用例

### TC-AUTH-001: 获取Token - 正常流程
| 属性 | 值 |
|-----|-----|
| **用例编号** | TC-AUTH-001 |
| **用例名称** | 使用正确的client_id和client_secret获取Token |
| **前置条件** | 有效的client_id和client_secret |
| **请求方法** | POST |
| **请求URL** | `/oauth2/token` |
| **请求头** | `Content-Type: application/x-www-form-urlencoded` |
| **请求体** | `grant_type=client_credentials&client_id={valid_id}&client_secret={valid_secret}` |
| **预期结果** | 返回200，响应包含access_token、token_type、expires_in |
| **验证点** | 1. success=true 2. access_token不为空 3. token_type="Bearer" 4. expires_in=3600 |

## 二、目录服务测试用例

### 2.1 创建目录

#### TC-DIR-001: 查询目录 - 查询根目录
| 属性 | 值 |
|-----|-----|
| **用例编号** | TC-DIR-016 |
| **用例名称** | 查询应用根目录 |
| **前置条件** | /app1/ 下存在子目录 |
| **请求方法** | GET |
| **请求URL** | `/api/directory/query?path=/app1/` |
| **请求头** | `Authorization: Bearer {token}`<br>`X-Path: /app1/` |
| **预期结果** | 返回200，success=true，obj为目录列表 |
| **验证点** | 1. 返回目录列表 2. 每个目录包含id、directoryName、fullPath等字段 |
