## 二、一句话定位（所有材料都围绕它）

> **写 YAML 就能跑接口测试，而且它不允许用例「绿了但什么都没校验」。**

三根支柱（对应三篇文章）：

1. **工程化**：YAML → 标准 pytest 用例，一条命令转换/运行/报告，能进 CI（01、02、06）；
2. **可信度**：生成期闸门 + 57 条防线登记 + 2545 条机器判据（03）；
3. **不失控的 AI**：文档 → 草稿，**判定永远在内核、转正必须人工、删包即回滚**（04）。

## 五、可直接使用的两段话术

**30 秒版（对负责人）：**
> 接口自动化最怕的不是跑不通，是**跑绿了却没测到东西**。InterfaceTester 写 YAML 就能跑接口测试，产物是标准 pytest 用例，能进 CI；它把"曾经造成假通过的每一种形态"逐条做成了生成期闸门和告警，**57 条防线都有回归用例守着**。另外它有个 AI 协作层：把接口文档变成用例草稿，但**判定永远在内核、草稿必须人工确认才进 `cases/`**——不失控。

**3 分钟版**：在上面基础上补三点——① `hconvert` 能把现有 Postman/HAR/OpenAPI 一键导成 YAML；② 22 个内置算子，含 JSON Schema / XPath / XSD 契约；③ 内网离线可装（两个 wheel + 锁版本清单），AI 可全本地（回环免 key），**没配就绝不出网**。

## 六、最有说服力的五个"可复跑证据"（建议现场演示）

| 演示 | 命令 | 期望结果 |
| --- | --- | --- |
| ① 一条用例端到端 | `hrun examples/data_management --html=reports/r.html --self-contained-html` | **实测 4 passed, 1 skipped** + 单文件报告（零外网、零数据库；两条 ERROR 日志是示例故意演示的 401/403） |
| ② **生成期闸门** | 把 `validate: - eq: [...]` 改成 `equall` → `python -m interfacetester make demo.yml` | **实测**：`FunctionNotFound: unknown assert comparator: equall` + **退出码 1** + **不生成** `*_test.py`；换成 Python 内置 `print` 同样被拦 |
| ③ **假通过对照** | `$env:QUICKSTART_RUN_CONTRAST="1"; hrun examples/quickstart/contrast_false_pass.yml` | **实测 1 passed（是绿！）**——断言字段名拼错的后果（伴随着"字段被忽略"告警）；配套 `contrast_assert_fail.yml` **实测 1 failed**。默认访问 `httpbin.org`，内网请改指本地 mock |
| ④ 存量迁移 | `python -m interfacetester convert --from curl --in examples/data/curl/curl_examples.txt --out converted/` | **实测**：生成 YAML + "导出即验证通过：load_testcase + hmake 干跑 + 语法检查" + 逐条告警（**含"没生成断言"的提示**、Authorization 已占位） |
| ⑤ AI 不调模型出草稿 | `python -m interfacetester_ai gen 文档.md --assertions-only` | **实测**：按接口段逐片出草稿 + 质量状态（`rejected·structure-rejected` / `needs_review·unknown-critical`）+ `unknowns` + `NEEDS_HUMAN.md`（**退出码 0 ≠ 可进 CI**） |

## 七、合规与口径红线（务必遵守）

1. **必须注明来源**：内核是 **HttpRunner v4.3.5 的二次开发分支**，**Apache-2.0**，随附 `LICENSE` + `NOTICE`；宣传材料**不得**暗示与上游有官方合作、背书或商标授权。
2. **不夸大 AI**：不得说"全自动生成用例直接进 CI"；正确表述是"**生成可复核的初稿，人工转正后进 `cases/`**"。
3. **不隐瞒边界**：宣传时至少带上"**4xx/5xx 不自动判失败**""**Thrift 实验性未验证**""**不支持压测/并发治理**"三条。
4. **数字要带口径**：引用产出率/判据数量时，**连日期与样本一起写**（如"2026-09-27 本机、15 篇 golden 文档"），因为**换模型/换机器必须重跑**。
5. **不要编造商务条款**：价格、SLA、支持范围由你们按实际模式填写（见 09 的 Q15 占位）。
