# 从 0 到 CI：10 分钟跑通第一条用例

> **目标读者**：想立刻上手的人（含不写代码的测试同学）
> **一句话主张**：装一个包、写一个 YAML、跑一条命令，出报告——**内网/离线也能全套跑通**。
> **发布建议**：做 demo 的脚本、新人培训第一篇、PoC 现场材料

---

## 一、3 分钟装好（Python ≥ 3.8）

```powershell
python -m pip install -e .            # 内核：得到 hrun / hmake / hconvert
python -m pip install -e interfacetester_ai --no-build-isolation   # 可选：AI 协作层，得到 haify
```

> ⚠️ 踩坑提示（已实测）：`haify` 声明在 **AI 包自己的** `pyproject.toml` 里，所以**只装内核不会有 `haify`**。
> 不装也能用等价入口：`python -m interfacetester_ai gen <文档.md>`。
> 装完自查一句：`haify -V` → 同时打印 **AI 层版本 + 内核版本**。

**CI 里要跑测试**：`pip install -e ".[test]"`（带 `pytest-xdist`，`pytest tests -n auto` 从约 90s 压到十几秒）。
**要测 XML/SOAP**：`pip install -e ".[xml]"`（lxml 是二进制依赖，所以放在 extra 里）。

## 二、5 分钟写出第一条用例

```
myproject/
├── debugtalk.py     # 项目标记（告诉框架"这里是一个项目根"）+ 放你的自定义函数
├── .env             # 环境变量（BASE_URL、密钥……不进 git）
└── login.yml        # 用例
```

```yaml
# login.yml
config:
  name: 登录
  base_url: ${ENV(BASE_URL)}
  variables:
    uid: 1001

teststeps:
  - name: 登录拿 token
    request:
      method: POST
      url: /api/login
      json: {username: admin, password: "${ENV(DEMO_PWD)}"}
    extract:
      - token: body.data.token          # 提取：jmespath
    validate:
      - eq: [status_code, 200]
      - eq: [body.code, 0]

  - name: 带 token 查询用户
    request:
      method: GET
      url: /api/user/info
      headers:
        Authorization: "Bearer $token"  # 用上一步提取的变量
    validate:
      - eq: [status_code, 200]
      - eq: [body.data.role, admin]
      - jsonschema_match: [body, "schemas/user.json"]   # 契约断言
```

**三个文件的分工（记住这张表就够了）**：

| 文件 | 作用 | 必填？ |
| --- | --- | --- |
| `debugtalk.py` | **门牌号**（项目根定位）+ 自定义函数库 | 强烈建议有（否则相对路径会跟着 cwd 漂） |
| `.env` | 环境变量来源（`${ENV(...)}` 读它） | 建议有（把地址/密钥从用例里拿出去） |
| `*.yml` | 用例本体 | 必须有 |

## 三、2 分钟跑起来

```powershell
hrun login.yml --html=reports/login.html --self-contained-html   # 转换 + 运行 + 出报告
hmake login.yml                                                  # 只想先看生成的 pytest 代码
```

**期望看到**：

- 终端逐步骤打印：请求/响应摘要、`assert status_code equal 200(int) ==> pass`；
- 报告：`reports/login.html`（**单文件**，可以直接发给人）；
- 日志：`logs/<用例id>.run.log`（DEBUG 级明细，含完整的请求/响应与断言结果，凭据已 `******`）；
- 生成的 pytest 用例：`login_test.py`（**产物，别手改**；要改就改 YAML）。

**零外部依赖的试跑**（不想连你们环境）：

```powershell
hrun examples/data_management --html=reports/report.html --self-contained-html
# 这个示例自带本地 mock，不依赖外网、不依赖数据库
# 期望结果：4 passed, 1 skipped（其中两条 ERROR 日志是示例**故意演示**的 401/403 场景）
```

## 四、想更进一步：三条建议

### 1. 先看"假通过"长什么样（比看文档快 10 倍）

仓库自带一组**默认跳过**的对照演示，看的就是"绿了但什么都没测到"：

```powershell
$env:QUICKSTART_RUN_CONTRAST="1"
hrun examples/quickstart/contrast_false_pass.yml     # 断言字段名拼错（validates）→ 实测 1 passed（是绿！）
hrun examples/quickstart/contrast_assert_fail.yml    # 同一个断言、字段名写对 → 实测 1 failed
```

两条并排看，"**写对 = 红、拼错 = 绿**"这个反差，就是第 03 篇讲的一切的由来。

- 拼错那条的用例**本身是绿的**，但终端会有一行告警：`存在无法识别的字段：['validates']，它们会被忽略`——**告警不是失败**，这正是它危险的地方；
- 这两条对照用例默认访问 `httpbin.org`；**内网请先起本地 mock**（`python tests/mock_server.py`）并把 `BASE_URL` 指过去。

### 2. 接 CI：两个模板直接抄

- GitHub Actions：`.github/workflows/test.yml`
- GitLab CI（内网常用）：`.gitlab-ci.yml`

**CI 主 job 用的确定性口径**（排除 6 个打公网的用例）：

```bash
python -m pytest tests -q \
  --deselect tests/step_request_test.py::TestRunRequest::test_run_request \
  ...（其余 5 条见 README §六）
```

你们自己的用例则更简单：

```bash
hrun cases/ --html=reports/report.html --self-contained-html --junitxml=reports/junit.xml
```

> 三个 CI 里最容易踩的坑（**已在 `docs/ci/README.md` 逐条写明**）：① mock 端口（非 root 环境改环境变量）；② 6 个外网用例在断网 CI 上必然失败 → 要 deselect；③ 离线装依赖（见下）。

### 3. 内网/离线部署

```powershell
# 在有网的机器上把两个 wheel 和锁定的依赖清单准备好，一起带过去
python -m pip install --no-index --find-links=./wheels -r requirements.txt
python -m pip install --no-index --find-links=./wheels interfacetester-5.0.1-py3-none-any.whl
```

仓库根**已经备好** `interfacetester-5.0.1-py3-none-any.whl` 与 `requirements.txt`（锁版本清单），离线打轮也已实测。

## 五、可选：让 AI 先帮你出草稿

```powershell
# 1) 不调模型先试一次（离线、可复现）：按接口段逐片出草稿
python -m interfacetester_ai gen 你的文档.md --assertions-only

# 2) 要调模型，显式配三样环境变量（不读项目 .env）
$env:INTERFACETESTER_AI_BASE_URL = "http://127.0.0.1:11434/v1"
$env:INTERFACETESTER_AI_MODEL    = "qwen2.5:14b"
$env:INTERFACETESTER_AI_SANDBOX  = "on"
python -m interfacetester_ai gen 你的文档.md --base-url http://你的测试环境

# 3) 人工确认后转正（唯一进 cases/ 的通道）
haify review --list
haify review --approve <草稿名> --approver <你的名字>
```

> **没配就一定不会出网**（退出码 2 + 打印配置指引），这是硬保证。

## 六、日常命令速查

| 想干什么 | 命令 |
| --- | --- |
| 转换 + 运行 + 报告 | `hrun 用例.yml --html=reports/r.html --self-contained-html` |
| 只转换（看生成的 pytest 代码） | `hmake 用例.yml` |
| 批量跑一个目录 | `hrun cases/` |
| 导入存量资产 | `hconvert --from har --in demo.har --out converted/` |
| 生成汇总 JSON | `hrun 用例.yml --save-tests` |
| 调日志级别 | `hrun 用例.yml --log-level=DEBUG` |
| 看版本 | `hrun -V` / `haify -V` |
| 生成用例草稿（AI） | `haify gen 文档.md --base-url http://host:port` |
