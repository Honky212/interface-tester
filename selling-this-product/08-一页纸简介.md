# 一页纸简介（邮件 / 群公告 / PPT 直接可用）

> **用法**：整页复制即可；面向管理层时只保留「一、二、六」三节

---

## 一、一句话

**InterfaceTester 是一套接口自动化测试框架：写 YAML 就能跑接口测试，并且它不允许用例「绿了但什么都没校验」。**

## 二、三句话说清价值

1. **写得快**：YAML/JSON 写用例 → 自动转成标准 pytest 用例 → 一条命令转换、运行、出报告。
2. **结果可信**：生成期就拦下拼错的算子名/非法写法；运行期不静默吞错；**57 条"曾经造成假通过"的形态逐条登记、有回归用例守着**。
3. **迁移与协作成本低**：curl / HAR / Postman / OpenAPI **一键导入**；产物就是 pytest 用例，**能进 CI、能进 IDE、能 diff 评审**。

## 三、三个硬数字（都可复跑）

| 数字 | 含义 |
| --- | --- |
| **22** | 内置断言算子（含 JSON Schema 契约、完整 XPath 1.0、XSD 契约） |
| **2545 passed / 0 failed** | 2026-09-27 本机全量机器判据（含元护栏与文档一致性判据） |
| **86.7% → 92.86%** | AI 辅助「文档 → 用例草稿」的接口片产出率（本地模型，带口径） |

## 四、能力一览（打勾即支持）

- **HTTP/HTTPS 全方法**、JSON/表单/文件上传/代理/客户端证书/流式
- **变量与函数**：`$var`、`${func()}`（项目自己的 `debugtalk.py`）、`${ENV()}`、CSV 数据驱动
- **提取与断言**：jmespath 提取 + 22 算子（相等/数值/长度/包含/字符串形态/JSON Schema/XPath/XSD）
- **用例复用**：`testcase:` 引用、步骤级 hooks、步骤级重试、用例级 skip、参数化笛卡尔积
- **认证**：OAuth2 Client Credentials 内置；签名/加密/HMAC/国密在 `debugtalk.py` 里实现
- **扩展协议**：SQL（MySQL，验证落库）、SOAP/XML（含零依赖退路）
- **报告日志**：单文件 HTML 报告、junitxml、每用例 `.run.log`、凭据统一脱敏
- **CI**：GitHub Actions + GitLab CI 模板现成；**离线/内网可安装**
- **AI 协作层（可选）**：文档 → 用例草稿（AI 只产草稿，**人工确认才进 `cases/`**）

## 五、上手只要三条命令

```powershell
python -m pip install -e .
hrun 我的用例.yml --html=reports/report.html --self-contained-html
# 零依赖试跑（自带本地 mock，不连外网）
hrun examples/data_management --html=reports/report.html --self-contained-html
```

## 六、边界（先说不是万能的）

- **不做**：性能压测、UI/移动端自动化、gRPC/WebSocket/MQ；
- **局限**：SQL 仅 MySQL；Thrift 实验性未验证；**HTTP 4xx/5xx 不自动判失败**（成败由 `validate` 定义）；
- **AI 的承诺边界**：把文档变成**可复核的用例初稿**，**不承诺**"无人审核自动进 CI"；
- **并发治理 / 测试数据管理 / 报告聚合**属框架之外，需另行投入。

## 七、许可与来源

内核 `interfacetester 5.0.1` 是 [HttpRunner](https://github.com/httprunner/httprunner) **v4.3.5** 的二次开发分支，采用 **Apache-2.0** 许可并附 `NOTICE`；AI 协作层 `interfacetester-ai` 是**独立发行的旁路包**（内核 0 改动，卸载即回滚）。
